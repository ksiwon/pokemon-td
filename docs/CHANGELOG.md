# 변경 이력 (Changelog)

이 파일이 패치노트의 **원본(single source of truth)** 이다.
인게임 패치노트 모달([`src/components/modals/PatchNotes.tsx`](../src/components/modals/PatchNotes.tsx))은
여기서 **유저에게 의미 있는 항목만 골라** 최근 몇 개 버전을 보여준다.

## 새 버전을 추가할 때

1. 이 파일 맨 위에 새 섹션을 추가한다. 버전 = 작업 브랜치 이름(`v2.24_xxx` → `v2.24`).
2. 유저에게 보일 항목이 있으면 `PatchNotes.tsx`의 `PATCH_NOTES` 배열 맨 앞에 추가하고,
   문구는 `ko.json` / `en.json`의 `patchNotes.*`에 넣는다. **두 언어 모두** 채운다.
3. 내부 리팩터·시뮬레이터·문서 작업은 여기만 적고 인게임에는 넣지 않는다.

분류는 `추가` / `변경` / `수정` / `내부` 네 가지만 쓴다.

> v2.23 이전 항목은 커밋 히스토리에서 역추적해 채운 것이다. 커밋 메시지에 남은
> 내용만 반영했으므로, 당시 실제로 나갔던 변경 중 메시지에 안 적힌 것은 빠져 있을 수 있다.

## v2.25 — 2026-08-30

UI 전면 개편 + 퀴즈 경제·랭킹 정리 + 자료실 신설.

### 추가
- **자료실.** 메인 메뉴 도움말 줄 다섯 번째 버튼. 탭 4개(싱글·스토리 / 멀티 /
  미니 포켓 / 퀴즈)에 데미지 계산식·확률·재화 수급표를 정리했다. 가이드가 "어떻게
  노느냐"를 알려준다면 자료실은 "어떤 수치로 도느냐"를 적어 둔 자리다.
- **퀴즈 종목별 재화 보상.** 그동안 재화를 주는 건 수능 모의고사뿐이었다.
  이제 종목 15개도 최고 정답 수에 따라 지급한다 — 액수는 모의고사의 **1/5**
  (10/16/24/32/50 코인, 0/1/2/3/5 별조각, 종목당 누적 132코인·11별조각).
  규칙은 모의고사와 같아서 구간마다 한 번만 받는다.

### 변경
- **UI 전면 개편.** "AI가 디자인한 것 같다"는 리뷰가 반복돼 UI 문법을 통째로 바꿨다.
  유리 카드·hover 떠오르기·둥근 모서리·그라디언트 CTA·별똥별 파티클을 걷어내고,
  나인슬라이스 도트 창틀 PNG + Galmuri11 + 하드 그림자 + ▶ 커서로 재작성했다.
  53개 파일이 `src/styles/tokens.ts` · `src/styles/pixel.ts` 를 단일 출처로 쓴다.
  기준 문서는 [`docs/DESIGN.md`](./DESIGN.md).
- **퀴즈 랭킹은 50문항 완주만 집계한다.** 점수가 '맞힌 개수'라서 문항 수가 섞이면
  보드가 무의미했다(10문항 만점 10점과 50문항 40점이 같은 줄). 10·30문항은
  연습용으로 남기고 개인 기록·재화에는 그대로 반영한다.
- **미니 포켓 가이드가 6장 → 4장.** 재화 수급표와 전투 계산식 슬라이드를 자료실로
  옮겼다. 슬라이드는 아이콘 + 한 줄 3개짜리 그릇이라 표를 담기에 나빴고, 처음 온
  사람에게 계산식부터 들이미는 순서도 아니었다. 가이드 하단에서 자료실로 바로 간다.
- **자료실에서 소스 파일 경로 표시를 뺐다.** 플레이어에게 `services/CardService.ts`
  같은 걸 보여 줄 이유가 없다. 어느 파일에 정의돼 있는지는 코드 쪽 주석으로 남겼다.
- 설정 화면 크레딧을 `Made by Siwon @ KAIST` 로.

### 수정
- **창 안쪽 여백이 제각각이던 문제.** 업적은 탭 줄이 제목보다 왼쪽으로 튀어나오고,
  자료실은 표가 창틀에 붙었으며, 전당은 좁은 화면에서만 본문이 머리띠보다 좁았다.
  머리띠·탭 줄·본문·표가 저마다 여백을 정하고 있었다 — 한 곳(`modalPadX`)에서만
  오게 했다. 값이 아니라 출처가 하나여야 안 갈린다.
- **제목 띠가 창틀에서 떠 있던 문제.** 창틀이 사방 12px을 먹는데 띠를 그 안에 넣어서,
  창틀과 띠 사이에 창 바탕이 띠처럼 남았다. 업적·전당은 띠가 아예 없거나 안쪽에
  떠 있어 자료실·랭킹과 제목 처리가 갈렸다 — 네 창을 같은 규칙으로 맞췄다.
- **탭과 필터가 같은 크기여서 층위가 안 보이던 문제.** 전당의 [최단 클리어 | 최고
  웨이브 | 내 기록] 아래에 [전체 맵 | …] 이 같은 얇은 칩으로 붙어, 두 줄이 한
  덩어리로 읽혔다. 주 탭을 한 단계 크게 하고 필터는 작은 칩으로 남겼다.
- **가로로 스크롤하는 탭 줄이 창틀에 붙어 잘리던 문제.** 스크롤 상자에 준 좌우
  여백은 내용과 함께 밀려서, 조금만 스크롤해도 첫 탭이 잘렸다. 여백은 바깥이,
  스크롤은 안쪽이 맡게 했다.
- **확인 대화상자·픽커·결과창의 좌변도 큰 창과 맞췄다.** 큰 창은 `창 + 안쪽 스크롤
  상자` 두 겹으로 좌변을 만드는데, 이 창들은 안쪽 상자가 없어 창의 기본 여백만
  남아 있었다. 게다가 그 위에 본문이 또 제각각(12·16·24px)으로 여백을 얹고 있었다.
  창 자신이 좌변을 만드는 껍데기(`ModalPlainBox`)를 만들어 여섯 창을 얹었다.
  진화 확인·웨이브 보상·웨이브 50 클리어·기술 선택·튜토리얼·멀티 결과.
- **토큰을 벗어난 글자 크기 12곳.** 13·18·19·22·30px처럼 4px 격자에 없는 값이
  남아 있었다. 아이콘은 `ICON`(12/16/20/24)으로, 글자는 `FONT`로 스냅했다.
  `ICON` 토큰은 만들어 놓고 실제로 쓰는 곳이 하나도 없었다 — 10곳에 연결했다.
- 인게임 HUD 숫자(24px)에 큰 글자용 그림자가 빠져 있던 것.
- **인게임 맵 툴팁이 잘리던 문제.** 커서가 맵 오른쪽·아래에 있으면 툴팁이 패널 밖으로
  나가 잘렸다. 이제 커서 위치에 따라 네 방향으로 뒤집는다.
- **툴팁이 안 사라지던 문제.** 커서가 맵 밖으로 빠져나가도 마지막 툴팁이 남아 있었다.
  Konva Stage는 도형 단위로 이벤트를 받아서 '스테이지를 벗어남'을 못 잡는다 —
  DOM 컨테이너에서 처리하도록 옮겼다.
- **같은 타입이 화면마다 다른 색이던 문제.** 타입 색 팔레트가 네 벌 있었다.
  테라스탈 타일(캔버스)과 그 타일을 설명하는 툴팁(DOM)이 서로 다른 색이었다.
  전부 `TYPE_COLOR` 한 곳으로 위임했다.
- **받침 있는 한글이 위아래로 잘려 보이던 문제.** 도트 폰트 기본 행간이 좁아
  괄호·슬래시와 받침이 깎였다. 행간을 1.5로 고정했다.
- 닫기·종료 버튼에서 창틀을 걷어냈다. 빨간 ❌ 이모지도 `✕` 글자로 바꿨다
  (오류 아이콘으로 읽혔다).
- 코드 주석에서 버드렉스 합체 재료 이름이 서로 뒤바뀌어 있던 것을 고쳤다
  (동작에는 영향 없음).

### 내부
- `npm run shots` — Playwright로 주요 화면을 `shots/` 에 캡처하는 도구. 빌드가
  통과해도 창틀이 삐져나오거나 글자가 잘리는 건 눈으로만 보인다.
  로그인이 필요한 화면(멀티 로비·속도전·랭킹·전당)도 게스트로 들어가 찍는다.
  두 가지가 갖춰져야 한다 — dev 서버가 **5173**일 것(API 키 리퍼러 허용이 포트
  단위다), 그리고 `.env` 의 App Check 디버그 토큰이 콘솔에 등록돼 있을 것.
  비워 두면 SDK가 프로필마다 새 UUID를 만들어 실행마다 403이 난다.
  브라우저 프로필을 남겨 재사용하므로 게스트 계정이 실행마다 쌓이지 않는다.
- `npm run ui:frames` / `ui:check` — 창틀 PNG 생성기와 팔레트 동기화 검사.
  `tokens.ts` 의 면색이 PNG에도 구워지므로 어긋나면 패널에 이음매가 보인다.
- 퀴즈 저장 스키마에 `rankedBest` · `claimedKindMilestones` 추가.
  `rankedBest` 를 `best`/`examBest` 와 분리한 이유는, 개인 기록이 문항 수를 가리지
  않아서 그대로 올리면 30문항으로 세운 점수가 50문항 보드에 올라가기 때문이다.
- 자료실 표의 수치 일부(퀴즈 마일스톤·팩 정의·레어도 가중치·폼 개수)는 코드에서
  import 해 만든다. 손으로 적으면 밸런스를 고칠 때 문서만 조용히 낡는다.
- 사용처가 사라진 `ShootingStarsBackground` 삭제.

## v2.24 — 2026-08-24

### 수정
- **같은 기술이 레벨업마다 반복 제안되던 문제.** 테오키스가 Lv5·7·9에서 나이트헤드만
  세 번 제안받는 등, 특정 포켓몬에서 기술 선택창이 무의미하게 반복됐다.
  원인은 기술 습득 레벨을 세대(version group)별로 따로 세던 것 —
  나이트헤드는 세대에 따라 Lv5/7/9, 텔레포트는 Lv10/13/17에 배우게 되어 있어
  그 레벨마다 각각 후보로 올라왔다. 이제 기술별 **최소 습득 레벨 한 번만** 제안한다.
  더불어 이미 장착 중인 기술, 이미 거절한 기술, 대기 중인 선택창에 이미 올라간 기술도
  후보에서 제외한다.
- **최고 웨이브 기록이 5의 배수로 내림되던 문제.** 예: 64웨이브까지 클리어했는데 60으로 기록.
  리더보드 갱신이 5웨이브마다만 일어나고(Firestore 무료 쿼터 절감), 게임오버 시점에
  최종 도달 웨이브를 올리는 경로가 없었다. 이제 게임오버 시 1회 더 기록한다
  (런당 쓰기 1회 추가). 기존에 저장된 기록은 소급되지 않으며, 다음 플레이부터 정확해진다.
